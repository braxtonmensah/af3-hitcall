## 2. Where the science landed

**Core result (verified, done).** Confident AI predictions of never-solved protein complexes are
usually correct: **81% of 146 human, 89% of 84 yeast**, versus 2% for low-confidence, judged against
structures released after the predictions. Survived five pre-registered attacks (homolog precedent
removed 81%/92%; shifted null 2%/1%; entry-cluster bootstrap unchanged; independent coordinate Fnat
80%/87-90%; threshold grid 57-88%). X-ray-only subset is 53% (n=19), the conservative bound.
What screens miss is **non-autonomous contacts**: small interfaces inside large assemblies.

**The discovery.** *M. pneumoniae* RNase J (MPN280) + MPN621 form a **2:2 heterotetramer**.
Evidence, five independent lines:
| Line | Number |
|---|---|
| Pooled AF3 screen | size-corrected ipTM 0.65, top 0.1% of 113,050 pairs |
| Dedicated AF3 (PREREG_AFJ, all 4 outcomes passed) | ipTM 0.84; **6/6 crosslinks < 30 A in 5/5 samples**; heterodimer leaves 3 at 51-63 A; decoy 0.12-0.17 |
| In-cell crosslinks, DSSO + DSS | same residue pairs in both chemistries |
| SEC-MS (published) | both peak at 297.8 kDa = 4.7x monomer; excludes 127 kDa 1:1, fits 254 kDa 2:2; only 5% of 437 proteins peak there |
| Essentiality (published) | MPN280 E/E; MPN621 E/E **+ E by colony isolation** |

Measured by us: MPN621 has lost **all 4** catalytic residues (RNase J keeps 4/4). Interface is
**178 contacts** per heterodimer vs 7-9 across; 65 + 66 residues. Interface only **24.6% identical to
human CPSF73** (which keeps 3/4 catalytic residues), so target the **interface, not the active site**.

**Honest limits.** MG_423 is **non-essential in M. genitalium** (essential in M. pneumoniae) — lead with
M. pneumoniae. The interaction itself is already in O'Reilly 2020's published PPI table (undiscussed),
and "probably non-catalytic" is in Lluch-Senar 2015's annotation. New here: the 2:2 architecture, the
validated model, measured catalytic loss, the SEC stoichiometry argument, the interface map.

**Nulls (9, all recorded):** CONTEXT, STRUCT, CLINVAR v1+v2, LITJEV, COMPOSE, COOP-P, plus per-protein
normalisation and interface PAE. Do not re-run these.

## 7. Gotchas learned the hard way

- AlphaFold Server freezes with many history rows. **Use the Search History box** to filter to one job;
  that drops the table to 1 row and stops the freezing. Real clicks for Continue/Confirm; scripted
  clicks on Confirm are unreliable. Verify name + chain lengths + third-chain prefix in the preview
  before confirming (bridge and ctrl can share lengths, e.g. pair 10 and 13).
- EMBO/embopress is bot-blocked. Get supplements via
  `europepmc.org/.../PMC4332154/supplementaryFiles` (returns a zip).
- The O'Reilly crosslink FASTA has corrupted residues (e.g. "K(a"). Use current UniProt sequences and
  locate peptides to resolve sites; that took usable links from 327 to 580.
- Europe PMC search: build URLs with `encodeURIComponent`, and use `pageSize=25` with `resultType=core`
  (100 intermittently returns an empty body).
- Don't pass `/c/...` git-bash paths to Windows Python; use `cygpath -w`.
