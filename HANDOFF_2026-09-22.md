## 3. Results so far (details and CIs in RESULTS.md)

**Headline:** AlphaFold interaction screens are excellent on complexes with a solved structural
precedent and weak on never-solved interactions. Published accuracy averages the two.

| Truth set | Precedented | Never solved |
|---|---|---|
| *M. genitalium* pooled AF3 vs STRING (Todor 2026) | 0.85 | 0.71 |
| In-cell crosslinks, *M. pneumoniae* (O'Reilly 2020) | 0.95 | 0.57 |
| Human AF2/FoldDock vs random pairs (Burke 2023) | 0.92 | 0.64 |

- *B. subtilis* / AF-Multimer recall replicates (53% vs 21%).
- **Time split:** complexes solved only after AF3's cutoff still score 0.81, so this is stability,
  not memorisation (just past the pre-registered bar).
- **Rejected ideas:** per-protein z-normalisation (H2), interface PAE vs ipTM (H3).
- **Post hoc:** the paper's pool-size figure is confounded (disjoint protein sections), and 4k pools
  equal 5k on matched pairs. A second pool replicate adds only +0.016. A bait's #1 hit is right 81%
  of the time if precedented vs 10% if never-solved.
- **Self-caught error:** the original precedent rule counted multi-entity homomers (6OJY) as
  co-complexes. The strict rule (`precedent_matrix_strict`) is now used, and H1 was unaffected.
- **HH2 (crosslinks on confident human models):** inconclusive (+0.14, CI -0.08..0.30).
- **CLINVAR v1:** failed its positive control. It compared interfaces against the whole protein,
  and core burial dominates. v2 (surface-matched) is pre-registered; see section 4.

**Practical facts for the pitch:** AF3 fits 4,352 tokens on an A100 40 GB (Big Red 200's GPU),
5,120 on 80 GB, and 1,280 on a V100 (Quartz). So Quartz can't run useful pools, Big Red 200 can run
4k pools, and 4k equals 5k.
